## 🎯 Screenshot Requirements

### Technical Specs:
- **Format:** PNG or JPG
- **Size:** 1200-1920px width recommended
- **Quality:** High resolution, clear text
- **File size:** Keep under 500KB if possible

### Content Guidelines:
- **Remove sensitive data:** No real API keys, passwords, or personal info
- **Use sample data:** Use demo/test accounts
- **Clean UI:** Hide browser extensions, use clean browser window
- **Consistent theme:** Use same theme (light or dark) across screenshots
- **Annotate if needed:** Add arrows or labels for clarity

### Naming Convention:
- Use kebab-case: `dashboard.png`, `learning-flow.png`
- Be descriptive: `topic-unlocking.png` not `screen1.png`

---

## 📝 How to Take Screenshots

### On Mac:
1. Press `Cmd + Shift + 4` for area selection
2. Or `Cmd + Shift + 3` for full screen
3. Save to `docs/screenshots/` folder

### On Windows:
1. Press `Win + Shift + S` for Snipping Tool
2. Or use `PrtScn` for full screen
3. Save to `docs/screenshots/` folder

### Browser DevTools:
1. Open DevTools (F12)
2. Toggle device toolbar (Cmd/Ctrl + Shift + M)
3. Set viewport size (e.g., 1920x1080)
4. Take screenshot
